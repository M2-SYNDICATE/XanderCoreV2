# Xander Core V2

**Версия:** `alpha 0.2.0`

---

## 📌 Описание

**Xander Core** — это модульное ядро голосового помощника **Xander (Ксандер)**.

Позволяет быстро создавать собственного помощника или дорабатывать уже существующую модель. Максимально гибкая архитектура: от простых текстовых команд до управления жестами и интеграции с LLM для интеллектуальных ответов.

### 💡 Особенности

- 🔧 Модульная архитектура
- 🧹 Легкая интеграция и расширяемость
- 🗣 ️ Поддержка голосового и текстового ввода
- 🤖 Возможность подключения моделей и внешних модулей

---

## 🚀 Установка

### ✅ Зависимости

- Python `>= 3.13`

---

### 🛠 Шаги установки

1. Клонируйте репозиторий:

```bash
git clone https://github.com/M2-SYNDICATE/XanderCoreV2.git
```

Или скачайте `.zip` архив и распакуйте.

2. Создайте и активируйте виртуальное окружение, установите зависимости:

Linux:

```bash
python -m venv venv
source venv/bin/activate
pip install -r req.txt
```

> ⚠️ **На Windows работа пока нестабильна.** Однако вы можете адаптировать ёё самостоятельно — автор готов внести проверенные правки в ветку `unstable`.

3. Настройте конфигурационный файл `data/config.yaml` под свои нужды.

4. Запустите ассистента:

```bash
python main.py
```

> 🗣 Если Xander не реагирует — обучите новую модель активационного слова на [этом сайте](https://givimad.github.io/rustpotter-create-model-demo/)

> 🛠 В будущих версиях планируется автоматическая настройка при первом запуске, включая обучение модели активационного слова.

## ⚙️ Настройка конфига

Конфиг поддерживает **шаблоны команд**, например:

```yaml
- template: "открыть {app}"
  action: ""
  arguments:
    app:
      - браузер->firefox
      - телеграм->telegram-desktop
      - дискорд->discord
      - терминал->kitty
```

📌 В этом примере, при команде "открыть телеграм" будет выполнено `telegram-desktop`.

> **Важно!** Название аргумента в `arguments:` должно соответствовать имени в `template`.

Оператор `->` указывает, какое значение будет возвращено. Например, `телеграм->telegram-desktop` означает: если пользователь сказал "открыть телеграм", то будет вызван `telegram-desktop`.

## 🧩 Установка модулей

1. Поместите папку модуля в директорию `modules/`.
   > 🔤 Название модуля желательно писать в стиле `CamelCase`.

2. Импортируйте модуль в `main.py`:

```python
from modules.<ИмяМодуля> import <Класс_или_Функцию>
```

3. Добавьте модуль в `pipeline`, например:

```python
core = Core(
    stt.recognize
    | <НовыйМодульКласс>.метод
    | processor.get_lemma
    | <НовыйМодульФункция>
    | processor.fuzzy_search
    | executor.execute,
    exception_handler=StandardTextExceptionHandler,
    verbose_except_output=True
)
```

📌 Каждый модуль в `pipeline` должен принимать один входной параметр и возвращать одно выходное значение.

## 🛠 Создание модулей

1. Создайте папку модуля в `modules/`, например: `modules/NewModule/`

2. Внутри создайте `main.py` с содержимым:

```python
from core import runnable

class NewModuleClass:
    def __init__(self, param1, paramN):
        self.param1 = param1
        self.paramN = paramN

    @runnable
    def execute(self, e):
        return e ** 2

@runnable
def NewModuleFunc(e, dup=2):
    return e * dup
```

3. Добавьте `__init__.py` в ту же папку:

```python
from .main import NewModuleClass, NewModuleFunc
```

Теперь эти функции/классы можно использовать в `pipeline`.
